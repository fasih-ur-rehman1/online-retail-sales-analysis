# 🛒 Online Retail Sales Analysis

## 📌 Project Overview

This project analyzes over **500,000 real-world retail transactions** using Python and Pandas.

The objective is to transform raw, messy business data into clean, reliable data and generate meaningful business insights through exploratory data analysis, feature engineering, summary reports, and data visualizations.

This project simulates a real freelance data analysis workflow, starting from raw data and ending with business-ready reports.

---

## 🎯 Business Objectives

- Clean messy retail transaction data
- Handle missing values and duplicate records
- Remove cancelled and invalid transactions
- Engineer new business features
- Analyze customers, products, countries, and monthly sales
- Generate professional reports
- Visualize important business trends

---

## 🗂 Dataset

**Dataset:** Online Retail Dataset

- More than **540,000 retail transactions**
- UK-based online retailer
- Public dataset available from the UCI Machine Learning Repository and Kaggle

> **Note:** The dataset is not included in this repository because of GitHub file size limits. You can download it from Kaggle or the UCI Machine Learning Repository.
The link is : https://www.kaggle.com/datasets/luisrenterialezano/retail-sales-dataset

## 🧹 Data Cleaning

The following cleaning steps were performed:

- Removed duplicate rows
- Removed cancelled orders
- Removed negative prices
- Removed zero-price transactions
- Removed missing product descriptions
- Converted InvoiceDate to datetime
- Converted CustomerID to nullable integer
- Created Revenue column
- Created Year, Month, and MonthName features
